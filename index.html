Methodology

Standalone CEBL analog of a WAR-to-dollar board. Production is Hollinger Game Score from 2026 Proballers accumulated box scores, not LEBRON. Do not treat these WARs as NBA-grade plus-minus.

  • Game Score = PTS + 0.4·FGM − 0.7·FGA − 0.4·(FTA−FTM) + 0.7·ORB + 0.3·DRB + STL + 0.7·AST + 0.7·BLK − 0.4·PF − TOV. Per-game GS is the season total divided by GP.
  • WAR = max(−1.5, (GS − 4.0) × GP / 80). Replacement GS is 4.0. No WAR without a box-score stint.
  • Market $/game = max(150, 280 + 118 × max(0, GS − 3)).
  • Cap value (headline): Designated Player = market (uncapped); Developmental = min(market, 300); everyone else = min(market, 2,000) SPC maximum.
  • Surplus = cap value − salary, both per game. Status bands: Underpaid if surplus ≥ $150, Overpaid if ≤ −$150, else Fair.
  • Cap hit: Standard = salary; Loyalty Player = 50% of salary; DP and Developmental = $0 against the $10,000/game active roster cap.
  • Origin is Canadian if listed nationality is Canadian, otherwise Import. Position is height-banded (≤188 PG, 189–196 SG, 197–203 SF, 204–208 PF, ≥209 C).
  • Projections 2027–29 are occupancy-adjusted cap value from 400 Monte Carlo draws (log shock σ = 0.18). Aging: <24 +3%; 24–27 +1%; 28–30 −3%; 31–33 −8%; 34+ −15%. Return rates: Import 0.45 / 0.25 / 0.15; Canadian 0.75 / 0.60 / 0.48; Developmental 0.55 / 0.40 / 0.28; age 32+ × 0.7. Non-return is $0. 2026 is observed, not simulated.
  • Multi-club seasons are merged on counting stats. Primary team is most minutes. Orange dots flag GP < 8.

Official 2026 club cap context: $10,000/game active ($240k) + $1,250/game inactive ($30k) = $270k. SPC $500–$2,000/game. One DP on the 14-man, DP pay outside the cap. Default table filter is GP ≥ 5.
